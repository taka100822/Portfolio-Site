## 工夫した点

デザインのテーマは「黒い製図台に引かれた企画書が、遊べるゲームに変わっていく」。色は黒と青だけで組み、動きはすべて「線画（企画）→ 実画像（実装）」の流れに沿わせています。

### Hero：作品タイトル画面の3D回転リング
各作品のタイトル画面を CSS 3D で円筒状に並べ、`requestAnimationFrame` で回転させています。奥側は青い線画、正面に来たカードだけ実画像に切り替わります。ドラッグで回せて（離すと慣性）、スクロールに合わせて加速しながら上へ流れ、クリックでその作品の詳細が開きます。

### 画像から線画を自動生成
`src/utils/lineArt.js` で、読み込んだ画像を canvas に描き、Sobel フィルタで輪郭を抽出して青い線画にしています。線画用の素材を別に用意する必要はありません。

### 代表作：線画 → 実画像と担当箇所の注釈
代表作の画像は画面に入ると線画から左へ塗るように実画像へ切り替わり、そのあと注釈線が伸びて「どこを担当したか」を指します。注釈は `works.js` の `annotations` に座標（%）で書くだけで追加できます。

### Timeline：実績解除トースト
受賞・発表の行がしばらく画面に留まると、ゲームの実績解除のようなトーストを1件ずつ表示します。ナビで通過しただけでは出さず、同じ実績は1回だけです。

### アクセシビリティ
OS の「視差効果を減らす」設定では回転や塗り替えを止めて静止表示にし、作品モーダルは Esc で閉じてフォーカスを元に戻します。

### 日本語 / 英語の切り替え
ヘッダーの「JA / EN」で切り替えます。初回はブラウザの言語設定で決まり、選んだ言語はブラウザに保存されます。文言は日本語だけを書けばよく、英訳は Claude Code に頼んで入れます（有料の API は使いません）。

## 英訳の運用

1. 日本語の文言（`src/constants/` や各コンポーネント）をそのまま更新する
2. Claude Code に「英訳を更新して」と頼む（未翻訳の文言を英訳して `src/i18n/en.json` に入れてくれる）
3. いつもどおりデプロイする

```bash
npm run deploy
```

`predeploy` で `npm run translate` が走り、未翻訳の文言があればデプロイを止めて一覧を出します。英語が抜けたまま公開されることはありません。使われなくなった訳は自動で消えます。

- **訳を手直ししたい**：`src/i18n/en.manual.json` に `{ "日本語": "English" }` を書く。`en.json` の訳より優先される
- **特定の文言を訳し直したい**：`npm run translate -- --retranslate "日本語の文言"` で未翻訳に戻してから Claude Code に頼む
- コンポーネントに日本語を直接書いた場合は `t('…')` で囲む。囲み忘れは `npm run translate` が警告します
